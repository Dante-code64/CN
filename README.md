# Crydan — RPG Medieval Social

App completo de RPG, economia, redes sociais, jogos e IA companheira — feito em HTML/CSS/JavaScript, com login e dados salvos de verdade no Supabase.

## O que tem no app
- RPG medieval: batalhas, missões, guildas, chefes, mapa
- Economia: banco, mercado, casas, empresas, empregos
- Social: conversas, comunidades, publicações, amigos, casamento
- IA Companheira configurável (nome, idade, gênero, personalidade)
- Central de Jogos: Jogo da Velha, Xadrez, Termo, Quiz, Conecta 4, Damas, 2048 e mais
- Perfil personalizável: banner animado ou em vídeo, molduras de avatar animadas, cores, fontes
- Login e conta real via Supabase (e-mail e senha)

## Rodando localmente
```
npm install
npm run dev
```

## Publicando
Veja o `DEPLOY_GUIDE.md` — é rapidinho.

## Tecnologia
- Frontend: HTML + CSS + JavaScript puro (sem framework)
- Build: Vite
- Backend: Supabase (autenticação + banco de dados Postgres)
- Hospedagem: Vercel
